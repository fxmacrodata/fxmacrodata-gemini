# Privacy

This Gemini CLI integration connects to `https://mcp.fxmacrodata.com`.
The host sends selected tool names, parameters and authentication information
to FXMacroData. The integration adds no analytics, storage, shell hooks or
background jobs. The host and service may retain requests under their own
policies. Never put credentials or private documents in tool parameters.

[FXMacroData privacy policy](https://fxmacrodata.com/privacy)
Contact: info@fxmacrodata.com.
